# E2E 上传样本

`twelvemonkeys-small-1x1.webp.base64` 是 TwelveMonkeys tag `twelvemonkeys-3.14.0` 中 `imageio/imageio-webp/src/test/resources/webp/small_1x1.webp` 的 Base64 文本形式，仅供真实文件上传 E2E 使用。

- 来源：https://github.com/haraldk/TwelveMonkeys/blob/twelvemonkeys-3.14.0/imageio/imageio-webp/src/test/resources/webp/small_1x1.webp
- 原始文件 SHA-256：`2f34799482dd5349b549d113fdaa188714d9737fe414e71541b752627bedbde3`
- 尺寸与用途：94 字节的 1×1 单帧 WebP；仅用于受控上传验证，不是产品资源。
