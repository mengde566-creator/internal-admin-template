# 材料索引

> 状态：生效  
> 版本：0.1  
> 更新日期：2026-07-18

`references/` 存放截图、PDF、外部文档、竞品信息和用户提供的其他输入材料。材料只用于帮助理解问题，不自动构成产品需求。

## 使用规则

- 材料必须由已确认需求文档关联，或由用户在当前任务中明确指定后才能作为实现参考。
- 材料与已确认需求冲突时，以已确认需求为准。
- AI 不得因为材料中存在某个页面、字段或功能就自行实现。
- 未实际读取的材料不得声称已经参考。
- 包含个人信息、凭据或商业敏感数据的材料不得提交到公开仓库。
