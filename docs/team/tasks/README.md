## 阅读边界

- 后续任务以 [版本任务交付协议](../VERSION_DELIVERY_PROTOCOL.md) 为准，不从历史任务复制流程；
- L0/L1 不创建任务书、实施报告和架构验收三件套；L2 也只在真实交接或不可逆授权时保留一份紧凑记录和一份最终证据；
- 历史任务、失败轮次和中间报告可通过 `0.1` 相关 Git 提交追溯，不得据此覆盖当前 README、愿景、架构和统一发布档案。
