# 0.1 历史任务与证据

本目录保存 `0.1.0` 封版过程，属于历史档案，不是模板使用者或后续功能必须照搬的工作流。

## 优先阅读

1. [0.1 封版任务总表](V0_1_RELEASE_PLAN.md)：任务状态与最终结论；
2. [0.1 最终发布验收矩阵](evidence/V01-13_RELEASE_ACCEPTANCE_MATRIX.md)：需求、代码、API、权限和测试追踪；
3. [0.1 发布级全量验证](evidence/V01-12_FULL_VALIDATION_REPORT.md)：固定 SHA 的本地、浏览器和 CI 证据；
4. [0.1 交付成本复盘](evidence/V0_1_COST_RETROSPECTIVE.md)：为什么旧流程成本过高，以及已经生效的 L0/L1/L2 止损规则。

## 阅读边界

- `V01-*.md`：当时的任务范围和授权；
- `evidence/V01-*.md`：实施、自审、失败与验收记录；
- 后续任务以 [版本任务交付协议](../VERSION_DELIVERY_PROTOCOL.md) 为准，不从历史任务复制流程；
- L0/L1 不创建任务书、实施报告和架构验收三件套；只有 L2 高风险任务使用完整模板；
- 历史记录保留当时事实，即使其中出现“待 V01-12”等旧状态，也不得据此覆盖当前 README、愿景和发布矩阵。
