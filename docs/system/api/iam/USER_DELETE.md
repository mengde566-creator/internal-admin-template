# 接口契约清单：删除用户（DELETE /api/users/{id}）

> 推导来源：已执行 Liquibase 变更集、`UserService#delete`、用户管理页面与 `IamFlowTest`。
> 本接口不接收请求体；用户 ID 按项目约定以字符串传输。

## 1. 路径参数与行为

| 参数或行为 | 规则 | 来源 | 前端对齐点 |
| --- | --- | --- | --- |
| `id` | 必填；目标用户 ID | **1**（`iam_user.id` 主键） | 从用户列表行传入，不允许手工拼接 |
| 删除方式 | 软删除，写入 `deleted=1` | **1**（`iam_user.deleted`）+ **3**（`@TableLogic`） | 二次确认文案说明“删除后不可恢复” |
| 删除后效果 | 正常列表不再返回该用户，账号不能登录；历史引用仍保留 | **3**（`UserService`、回归测试） | 成功后精确失效用户列表查询 |
| 保护规则 | 初始化管理员（id=`1`）与当前登录账号不得删除 | **3**（`UserService#delete`） | 当前列表中的删除操作仍以接口校验为准 |
| 审计 | 成功记录 `USER_DELETE` / `SUCCESS` | **3**（`AuditRecordApi` 调用） | 无额外前端字段 |

## 2. 成功响应

- `200`：`{ "code": "OK", "data": null, "message": "成功" }`
- 删除为不可恢复的软删除；本版本没有恢复或回收站接口。

## 3. 错误场景与文案

| 场景 | 状态码 | 文案 | 前端对齐点 |
| --- | --- | --- | --- |
| 未登录 | 401 | 未登录或登录已失效 | 跳转登录页 |
| 无 `iam:user:manage` 权限 | 403 | 无权限执行该操作 | 隐藏管理入口；接口继续兜底 |
| 用户不存在或已删除 | 404 | 用户不存在 | 刷新列表并显示明确错误 |
| 删除初始化管理员 | 400 | 不能删除初始化管理员 | 显示服务端原始业务提示 |
| 删除当前登录账号 | 400 | 不能删除当前登录账号 | 显示服务端原始业务提示 |
| 系统错误 | 500 | 系统内部错误 | 通用错误提示，不伪装为删除成功 |

## 4. 走查结论（用户视角）

- [x] 删除前显示不可恢复确认；
- [x] 成功后刷新用户列表；
- [x] 保护规则、未登录、越权和不存在均有明确失败语义；
- [x] 删除后的账号无法重新登录，且历史审计仍可追溯。
