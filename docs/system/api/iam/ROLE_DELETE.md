# 接口契约清单：删除角色（DELETE /api/roles/{id}）

> 推导来源：已执行 Liquibase 变更集、`RoleService#delete`、角色管理页面与 `IamFlowTest`。
> 本接口不接收请求体；角色 ID 按项目约定以字符串传输。

## 1. 路径参数与行为

| 参数或行为 | 规则 | 来源 | 前端对齐点 |
| --- | --- | --- | --- |
| `id` | 必填；目标角色 ID | **1**（`iam_role.id` 主键） | 从角色列表行传入 |
| 引用校验 | 仅有有效用户引用时拒绝删除；软删除用户留下的关联不构成有效引用 | **3**（`UserRoleMapper#selectUsernamesByRoleId`、回归测试） | 直接展示服务端返回的用户名列表 |
| 删除方式 | 先删除角色—权限关联，再物理删除角色 | **3**（`RoleService#delete`） | 成功后精确失效角色列表查询 |
| 审计 | 成功记录 `ROLE_DELETE` / `SUCCESS` | **3**（`AuditRecordApi` 调用） | 无额外前端字段 |

## 2. 成功响应

- `200`：`{ "code": "OK", "data": null, "message": "成功" }`
- 角色无有效用户引用时可以删除，其对应权限关联一并删除；本版本没有角色恢复接口。

## 3. 错误场景与文案

| 场景 | 状态码 | 文案 | 前端对齐点 |
| --- | --- | --- | --- |
| 未登录 | 401 | 未登录或登录已失效 | 跳转登录页 |
| 无 `iam:role:manage` 权限 | 403 | 无权限执行该操作 | 隐藏管理入口；接口继续兜底 |
| 角色不存在 | 404 | 角色不存在 | 刷新角色列表并显示明确错误 |
| 角色仍被有效用户引用 | 400 | 该角色正被用户 `[用户名…]` 使用，请先解除分配后再删除 | 逐字显示服务端业务提示，点名引用用户 |
| 系统错误 | 500 | 系统内部错误 | 通用错误提示，不伪装为删除成功 |

## 4. 走查结论（用户视角）

- [x] 删除前有二次确认；
- [x] 有效用户引用时，错误提示点名引用用户；
- [x] 软删除用户的残留关联不会错误阻塞删除；
- [x] 成功后刷新角色列表，并记录审计。
