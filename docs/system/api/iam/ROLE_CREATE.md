# 接口契约清单：创建角色（POST /api/roles）

> 示范文件：验证"材料驱动的判断"（WORKING_MODEL 12.6 / INTERFACE_CONTRACT §0）真实可用。
> 本清单由 AI 从已有材料推导，推导来源逐项标注；无业务决策点，用户无需参与。

## 1. 请求字段（来源标注：1=表结构 / 2=需求 / 3=现有代码 / ⚠=业务决策点）

| 字段 | 必填 | 校验 | 来源 | 前端对齐点 |
| --- | --- | --- | --- | --- |
| code | 是 | ≤64 字符；唯一；建议大写蛇形 | **1**（iam_role.code VARCHAR(64) NOT NULL UNIQUE）；格式惯例来自 **3**（现有 SYSTEM_ADMIN/CONTENT_EDITOR） | 表单 required + maxlength=64 + 大写提示 |
| name | 是 | ≤100 字符 | **1**（iam_role.name VARCHAR(100) NOT NULL） | 表单 required + maxlength=100 |
| permissionCodes | 否 | 必须来自代码注册的权限列表；可空数组 | **3**（现有实现校验权限注册表） | 多选组件，选项来自权限选项接口 |

排除的内部字段：id、created_at、updated_at（服务端生成）。

## 2. 成功响应

- `{ "code": "OK", "data": { "id": "<字符串ID>" }, "message": "成功" }`
- ID 按项目约定字符串传输（避免前端精度丢失）。

## 3. 错误场景与文案（来源 3：现有实现文案）

| 场景 | 状态码 | 文案 | 前端对齐点 |
| --- | --- | --- | --- |
| 未登录 | 401 | 未登录或登录已失效 | 跳登录页 |
| 无 iam:role:manage 权限 | 403 | 无权限执行该操作 | 按钮隐藏 + 接口兜底 |
| code 为空/超长 | 400 | 角色编码不能为空 / 角色编码长度不能超过 64 | 表单规则已拦截 |
| code 重复 | 409 | 角色编码已存在 | 提交后错误就地提示 |
| permissionCodes 含未注册权限 | 400 | 包含未注册的权限编码 | 选项来自权限接口，异常时提示 |
| 系统错误 | 500 | 系统内部错误 | 通用提示 |
