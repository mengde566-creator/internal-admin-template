# 接口契约清单：创建用户（POST /api/users）

> 示范文件：验证"材料驱动的判断"（WORKING_MODEL 12.6 / INTERFACE_CONTRACT §0）真实可用。
> 本清单由 AI 从已有材料推导，推导来源逐项标注；无业务决策点，用户无需参与。

## 1. 请求字段（来源标注：1=表结构 / 2=需求 / 3=现有代码 / ⚠=业务决策点）

| 字段 | 必填 | 校验 | 来源 | 前端对齐点 |
| --- | --- | --- | --- | --- |
| username | 是 | ≤64 字符；唯一 | **1**（iam_user.username VARCHAR(64) NOT NULL UNIQUE） | 表单 required + maxlength=64；提交前可查重提示 |
| displayName | 是 | ≤100 字符 | **1**（iam_user.display_name VARCHAR(100) NOT NULL） | 表单 required + maxlength=100 |
| password | 是 | 8-64 字符 | **3**（CreateUserDTO @Size(min=8,max=64)；表结构仅 password_hash VARCHAR(255) 无法推导强度） | 表单 required + 密码框 + 长度提示 |
| roleIds | 否 | 每个 ID 必须存在；可空数组 | **1**（iam_user_role 关联表）+ **3**（现有实现校验角色存在） | 多选组件；空数组=不分配角色 |
| department_id | — | 不进入请求（当前固定根部门） | **3**（现有实现固定赋值） | 不展示 |

排除的内部字段：password_hash、password_changed、created_at、updated_at、deleted（不进入请求/响应）。

## 2. 成功响应

- `{ "code": "OK", "data": { "id": "<字符串ID>" }, "message": "成功" }`
- ID 按项目约定字符串传输（19 位雪花 ID，避免前端精度丢失）。

## 3. 错误场景与文案（来源 3：现有实现文案）

| 场景 | 状态码 | 文案 | 前端对齐点 |
| --- | --- | --- | --- |
| 未登录 | 401 | 未登录或登录已失效 | 跳登录页 |
| 无 iam:user:manage 权限 | 403 | 无权限执行该操作 | 按钮隐藏 + 接口兜底 |
| username 为空/超长 | 400 | 账号不能为空 / 账号长度不能超过 64 | 表单规则已拦截，双保险 |
| username 重复 | 409 | 账号已存在 | 表单提交前可查重，提交后错误就地提示 |
| 密码长度不符 | 400 | 初始密码长度需在 8-64 之间 | 表单规则已拦截 |
| roleIds 含不存在角色 | 400 | 包含不存在的角色 | 多选数据来自角色列表，异常时提示 |
| 系统错误 | 500 | 系统内部错误 | 通用提示 |
