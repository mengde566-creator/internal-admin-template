# 仓储操作规则（合成测试资料，当前版）

本资料是供测试使用的合成制度样本，当前生效版本为 v2。实时库存数字必须从仓储业务查询取得，本文只提供操作规则。

## 入库记录

入库完成时记录物品、数量、单位、仓库和库位。入库记录应带有发生时间和操作说明，便于之后核对库存事实。

## 出库前检查

出库前必须核对当前可用余额。请求数量超过可用余额时应拒绝，系统不得形成负库存。

## 调拨移动

调拨必须同时形成来源位置和目标位置的移动记录。来源扣减与目标增加属于同一业务操作，不能只记其中一侧。

## 盘点调整

盘点发现差异时，以新的盘点调整记录修正余额，并填写差异原因。盘点不直接覆盖历史流水。

## 错误流水处理

错误流水不得修改或删除。应使用新的盘点调整记录说明更正原因，并保留原操作与后续调整的关联。

## 查询责任

制度条款不能替代实时仓储事实。查询数量、位置和移动时，必须以业务系统当前返回为准。
