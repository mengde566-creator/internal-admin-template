## 安全/权限用例

- 未登录访问草稿/发布接口 → 401；
- editor 权限用户可编辑草稿、不可发布（403）；
- 公开接口不泄露未发布/已撤回内容（404 而非数据）；
- CSRF：发布/撤回为状态变更，无 token 被 403 拦截。

## 数据完整性用例

- 单例表最多一行（CHECK id=1）；
- 发布/撤回/审计同事务（失败回滚旧快照有效）；
- 图片双通道：管理端（edit 权限，草稿预览可读）/ 公开（引用校验）。
