## 装配与裁剪契约（创建模块时必填）

本节是可选模块的唯一装配登记入口。创建或派生模块时必须按实际代码填写，不能复制其他业务模块清单，也不能把历史证据当作当前源装配。

### 源装配点

| 装配面 | 当前事实 | 裁剪动作 |
| --- | --- | --- |
| Maven reactor 与 app 依赖 | `backend/pom.xml`、应用 POM 中的模块声明 | 记录新增模块与直接依赖；裁剪时从 reactor 和 app 依赖一并移除 |
| 组件/Mapper 扫描 | `Application` 的组件扫描与 `@MapperScan` | 记录包路径；裁剪时移除对应扫描条目并检查残留 Bean |
| Liquibase 聚合 | 应用 changelog 主入口中的本模块变更集 | 记录变更集文件；不得修改已发布文件或自动修复业务数据 |
| 权限与审计 | 中央权限目录、公开审计 API 及调用动作 | 记录权限语义和动作归属；禁止新增双权限兼容、权限 SPI 或通用动作注册表 |
| Controller / OpenAPI | 本模块 Controller、匿名命名空间和生成入口 | 记录路由、权限与公开/受保护边界；裁剪后由真实代码重新生成契约 |
| 前端路由与导航 | 路由、导航、页面模块与直接导入 | 记录入口与权限体验层；裁剪时移除专属页面和残留导入 |
| 前端测试与质量 | package 脚本、Vitest、Playwright、E2E 及统一质量入口 | 记录受影响测试和命令；只保留仍有调用方的检查 |
